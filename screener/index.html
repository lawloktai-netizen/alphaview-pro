Data and method

  • Data source: Yahoo Finance via the free, open-source yfinance library. No API key needed, and it covers US and HK (.HK) listings. Yahoo provides about 4 to 5 years of annual statements, so "5-year" tests use the longest span available. The span used is shown beside each value.
  • Market cap: converted to HKD at the latest FX rate, so the 300億 threshold applies the same way to every market.
  • FFO (REITs): net income + D&A + non-cash property items (revaluation, disposal gains, impairments), taken from the cash-flow statement.
  • Quarterly EPS: taken from the Yahoo earnings calendar. Many HK companies report half-yearly, so this test shows "n/a" for them. The course says to check half-year results by hand.
  • Manual criteria: peer ranking, products and services, industry type, and management background need judgement, so they are not scored here.
  • For study only, not investment advice. Check key figures against the company's filings.
